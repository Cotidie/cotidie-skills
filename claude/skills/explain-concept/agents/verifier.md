# 검증원 프롬프트

Phase 5에서 대조할 항목이 10개를 넘을 때 2~4명 띄운다. **작성자가 아닌 에이전트여야 한다.**
같은 머리가 쓰고 검산하면 확증 편향이 그대로 통과한다.
펜스 안이 그대로 넘어가는 프롬프트 본문이고, 아래 세 줄은 넘기지 않는다.

- 에이전트: general-purpose
- description: `검증: [항목 범위]`
- model: 세션 모델

````text
문서에 실린 수치와 인용문을 원문과 대조하는 일이다. 문서를 고치지 않는다.

## 대조할 항목
[항목마다: 문서에 실린 값 또는 인용문 + 출처 URL·섹션]

## 규칙
- 항목마다 원문을 직접 연다. 기억이나 추론으로 판정하지 않는다.
- 원문을 열 수 없으면 NOT FOUND다. 비슷한 다른 출처로 대신하지 않는다.

## 반환 형식
| 항목 | 판정 | 원문 근거 한 줄 |
판정은 셋 중 하나만 쓴다.
- CONFIRMED: 원문과 값·문구가 일치
- DRIFT: 원문에 있지만 값이나 문구가 다르다. 원문 값을 함께 적는다
- NOT FOUND: 그 출처에서 찾지 못했다
````
