# 디자인 원칙 (이식용)

특정 런타임의 디자인 스킬 없이도 쓸 수 있게 보편 원칙만 뽑았다. HTML 산출물을 만들 때 읽는다.

---

## 1. Structure is information

구조 장치는 내용에 대해 참인 것만 담는다. 장식으로 쓰면 독자에게 거짓 신호를 준다.

| 장치 | 쓸 수 있는 조건 | 못 쓰는 예 |
|---|---|---|
| 번호(01/02/03) | 실제 순서 또는 순위 | 병렬 항목에 번호를 붙여 순서인 척 |
| 연표 | 날짜가 인과를 담을 때 | 같은 해에 나온 무관한 것들을 세로로 세움 |
| 대칭 카드 | 두 항목이 대등한 선택지 | 주제와 곁가지를 같은 크기 카드로 |
| 크기·굵기 | 중요도 차이가 실제로 있음 | 모든 섹션을 같은 무게로 |
| 아이콘·이모지 | 사실상 없음 | 섹션 마커로 이모지 |

**검산:** 장치마다 "이게 왜 참인가" 한 줄. 못 쓰면 뺀다.

## 2. 강조는 색이 아니라 밝기로

- 바탕(`--ground`)을 순백이 아니라 살짝 회색으로 둔다. 예: `#EDEFF0`
- 강조 블록(`--surface`)을 흰색으로 둔다. 색 없이 떠오른다.
- 색 강조는 정보 위계를 흐린다. 색은 **정체성**(주체 A는 청록, 주체 B는 호박색)에만 쓴다.
- 의미색(정상/주의/위험)은 정체성 색과 분리한다.

## 3. 중립색을 고른다

순수 회색(#888)은 "안 고른 것"처럼 보인다. 강조색 쪽으로 살짝 기운 회색이 "고른 것"처럼 보인다.
순백과 근검정도 주제에 맞으면 정당하다. 요점은 물려받지 말고 고르는 것.

## 4. 팔레트는 주제의 세계에서 끌어온다

| 주제 | 유래 |
|---|---|
| 영상 스트리밍 | SMPTE 컬러바(시안·황색), 18% 그레이 카드 |
| 데이터베이스 | 인쇄 회로 기판, 터미널 인광체 |
| 생물학 | 염색 시약, 현미경 필드 |
| 금융 | 신문 시세표, 원장 용지 |

주제의 재료·계측기·전문 용어에서 시작하면 템플릿처럼 보이지 않는다.

## 5. 피할 AI 기본값

사용자가 명시적으로 요구하면 그때는 따른다. 아무 지정이 없을 때 이것들을 고르지 않는다.

1. 크림색(#F4F1EA) 바탕 + 세리프 제목 + 테라코타 강조
2. 근검정 바탕 + 애시드 그린 또는 주홍 한 점
3. 보라→파랑 그라디언트 히어로
4. Inter, Space Grotesk를 기본값으로
5. 이모지 섹션 마커, 전부 가운데 정렬, 어디나 둥근 모서리, 카드 왼쪽 컬러 바

## 6. 타이포그래피

- 역할 2개면 충분하다: 본문·제목용 하나, 라벨·수치용 모노 하나.
- 한국어는 한글 지원 확인. `IBM Plex Sans KR`, `Noto Sans KR`, `Gowun Dodum` 등.
- 본문 폭: 라틴 65자, 한글은 40자 안팎. `max-width: 40rem` 근처.
- 숫자가 세로로 정렬되는 곳(표, 차트, 연도)은 `font-variant-numeric: tabular-nums`.
- 제목에 `text-wrap: balance`.
- 대문자 라벨에는 `letter-spacing: .12em`.

## 7. 두 테마

뷰어 상태는 셋이다: 명시적 라이트, 명시적 다크, 아무 표시 없는 시스템 기본.

```css
:root{ /* 라이트 팔레트 전체를 여기에 */ }
@media (prefers-color-scheme: dark){
  :root:not([data-theme="light"]){ /* 토큰만 재정의 */ }
}
:root[data-theme="dark"]{ /* 토큰만 재정의 */ }
```

**규칙 셋**
1. 색은 반드시 `:root`에 정의한다. 미디어쿼리 안에서만 정의된 색은 시스템 기본 상태에서 적용되지 않는다. 이것이 아티팩트가 안 읽히는 대표 원인이다.
2. `body`에 토큰 배경색을 명시한다. 투명 배경은 호스트 테마를 빌려 온다.
3. 컴포넌트는 토큰만 참조한다. 리터럴 색을 직접 쓰지 않는다.

단일 테마로 확정할 수도 있다. 그럴 땐 미디어쿼리를 아예 빼되 배경과 모든 색을 명시한다. 누락이 아니라 선택이어야 한다.

## 8. 레이아웃

- 형제 요소 간격은 flex/grid + `gap`. 개별 margin은 무너지거나 겹친다.
- 넓은 것(표, 코드, 다이어그램)은 자기 컨테이너에 `overflow-x: auto`. body가 가로로 스크롤되면 안 된다.
- 셀렉터 특이도 충돌 주의. `.section`과 `.cta`가 서로의 여백을 지우는 사고가 흔하다.
- 키보드 포커스에 보이는 상태를 준다. `:focus-visible`.
- `prefers-reduced-motion` 존중.

## 9. 자립성

- 외부 호스트 요청은 대부분 차단된다. CSS·JS는 인라인, 이미지는 data URI.
- 웹폰트는 Google Fonts만 허용되는 환경이 많다. 어느 쪽이든 실제 대체 스택을 적는다.
- 생성형 그래픽은 긴 SVG path를 손으로 쓰지 말고 Canvas를 쓴다.

## 10. 제목

- 문서 제목은 짧은 명사구 2~4단어. 주제를 특정해야 한다.
- 콜론이나 대시 뒤에 설명을 붙이지 않는다. 설명은 본문 첫 줄로.
- 일반 명사만 남기고 고유한 부분을 지우면 안 된다. "RTSP와 HLS"는 되고 "프로토콜 비교"는 안 된다.
