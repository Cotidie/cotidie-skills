# 구조 비평가 프롬프트

Phase 5에서 하나 띄운다. **조사 노트를 주지 않는다.** 완성된 문서만 보고 판정해야
독자가 실제로 받는 것을 재는 셈이 된다.
펜스 안이 그대로 넘어가는 프롬프트 본문이고, 아래 세 줄은 넘기지 않는다.

- 에이전트: general-purpose
- description: `구조 검산: [문서 이름]`
- model: 세션 모델

````text
완성된 문서 하나를 구조 관점에서만 검산하는 일이다. 내용의 옳고 그름은 보지 않는다.

## 문서
[파일 경로]

## 판정할 것
1. 구조 장치마다 "이게 왜 참인가"를 답한다. 번호는 실제로 순서·순위일 때만, 연표는 날짜가 인과를
   담을 때만, 대칭 카드는 두 항목이 대등한 선택지일 때만, 차트는 비교할 수치가 실제로 있을 때만
   쓸 수 있다. 못 답하는 장치는 "근거 없음"으로 표시한다.
2. lede 커버리지 매핑을 처음부터 다시 계산한다. lede 문장마다 어느 섹션을 덮는지 적고,
   어느 섹션에도 안 걸리는 문장과 어느 문장에도 안 걸리는 섹션을 각각 나열한다.

## 반환 형식
| 구조 장치 | 위치 | 왜 참인가 / 근거 없음 |
| lede 문장 | 덮는 섹션 |
마지막에 미커버 섹션 목록과 지엽적 lede 문장 목록을 한 줄씩 적는다.
````
